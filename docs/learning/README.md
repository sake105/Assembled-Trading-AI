Learning-Ordner — Projekt-spezifisches Wissen
============================================

Dieser Ordner sammelt **Incidents, Patterns, Anti-Patterns und Checklisten**, die speziell für dieses Projekt gelten.

Ziele:
- **Incidents**: Jedes relevante Problem (Bug, Incident, Outage) wird einmal sauber dokumentiert.
- **Patterns**: Bewährte Lösungsansätze, die wir wiederverwenden wollen.
- **Anti-Patterns**: Dinge, die wir bewusst vermeiden wollen (mit Beispielen).
- **Checklists**: Wiederkehrende Abläufe (PR, Release, Runbooks) als kurze, praktische Leitplanken.

Regel:
- **Jeder Bugfix braucht einen Incident-Eintrag + Tests.**
  - Mindestens: `docs/learning/incidents/INC-XXXX-*.md` aus dem Template kopieren.
  - Fix muss durch **neuen oder erweiterten Test** abgedeckt sein.

Weiterführende Übersicht:
- Siehe `index.md` für eine vollständige Navigation über alle Incidents, Patterns, Anti-Patterns, Checklists und Cursor-Dokumente.
